Offline test (run before every demo)

  1. With internet on, open this page and wait until Offline readiness shows Ready.
  2. Turn Wi-Fi off, or in Chrome DevTools open Network and choose Offline.
  3. Reload the page. It should load normally with the offline banner at the bottom.
  4. Press Save a test change twice. Waiting to sync goes up.
  5. Turn Wi-Fi back on. The banner shows syncing, then All changes synced.
